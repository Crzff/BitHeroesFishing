# v0.1.0-beta.1 — Primera beta pública

Bit Heroes Fishing Bot para Windows, basado en AUDIT-R3.15.

## Descargar e instalar

1. Descarga **BitHeroesFishing-v0.1.0-beta.1-source.zip** de Assets y descomprímelo.
2. Instala **Python 3.13 de 64 bits**, Tcl/Tk, pip y Python Launcher desde python.org.
3. Ejecuta **INSTALAR.bat**, después **COMPROBAR.bat**.
4. Abre el juego en Google Chrome, pantalla principal 1920×1080, START visible.
5. Ejecuta **ABRIR_BOT.bat** y pulsa INICIAR BOT. **F8 detiene ambos motores.**

La descarga **no es un ejecutable portable**. La primera instalación necesita
Internet para descargar dependencias. Abrir el panel no inicia la pesca.
