# Seguridad

Proyecto beta para automatización local. No ofrece protección frente a sanciones
del juego ni garantiza un resultado seguro en cualquier configuración.

No publiques credenciales, datos personales o detalles de una vulnerabilidad
explotable en un Issue público. Si el repositorio ofrece **Security → Report a
vulnerability**, usa ese canal privado. Si no está disponible, abre un Issue
sin detalles sensibles para solicitar un canal privado al mantenedor.

Instala Python desde python.org y dependencias desde PyPI. Comprueba los hashes
de Release y revisa alertas del antivirus: no las desactives para ejecutar el bot.

El enlace Ko-fi es externo. El bot no pide tarjetas, credenciales ni tokens de
GitHub, no procesa pagos y no exige apoyo económico para funcionar.
